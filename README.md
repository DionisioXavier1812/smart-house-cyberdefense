Projeto de defesa cibernética aplicado a uma casa inteligente (Smart House), com foco em Blue Team, DFIR, MITRE ATT&CK, logs simulados, IoCs, incidentes e playbooks. O cenário simula uma residência com dispositivos IoT, automação residencial, rede segmentada e monitoramento de segurança.

Inclui:

DFIR

MITRE ATT&CK

Logs simulados

IoCs

Playbooks

Threat Modeling

Incident Response

🎯 Objetivo do Projeto
Demonstrar segurança aplicada em ambiente de casa inteligente (Smart House).

Simular incidentes envolvendo dispositivos IoT e automação residencial.

Mapear técnicas MITRE ATT&CK em contexto doméstico.

Produzir documentação DFIR completa (timeline, evidências, relatório final).

Servir como portfólio profissional para Blue Team / SOC / DFIR.

🚀 Conteúdo do Projeto
🔹 Cenário Principal
Residência inteligente com:

rede doméstica segmentada (IoT / usuários)

dispositivos IoT (câmeras, fechadura inteligente, sensores)

automação residencial (hub central)

monitoramento de eventos e logs

🔹 Ameaças Simuladas
Comprometimento de câmera IP

Intrusão em fechadura inteligente (Smart Lock)

Abuso de assistente de voz

Pivoting via dispositivos IoT para rede interna

🔹 Cadeia de Ataque
Fluxos de ataque modelados para:

acesso inicial

execução

persistência

movimento lateral

exfiltração

🔹 Ambientes
