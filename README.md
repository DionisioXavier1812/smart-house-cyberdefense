## ?? Conteúdo do Projeto

### ?? Cenário Principal
Residência inteligente com rede segmentada, automação, IoT e monitoramento.

### ?? Ameaças Simuladas
- Câmera IP comprometida
- Smart Lock destravado indevidamente
- Assistente de voz abusado
- Pivoting via IoT

### ?? DFIR
Timeline, evidências, análise, correlação e relatório final.

### ?? Logs e IoCs
Logs brutos, syslog, dumps, outputs Zeek/Suricata, IoCs extraídos.

### ?? MITRE ATT&CK
T1040, T1078, T1059, T1021, T1041.
