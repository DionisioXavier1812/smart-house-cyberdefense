# Playbooks

## Câmera IP
1. Contenção: bloquear IP, revogar sessão, desativar acesso remoto
2. Validação: revisar logs, confirmar alterações, validar firmware
3. Erradicação: alterar credenciais, atualizar firmware
4. Recuperação: reativar acesso remoto com MFA, monitorar 48h
5. Lições: remover credenciais padrão, alertas de login

## Smart Lock
1. Contenção: desativar controle remoto, bloquear IP suspeito
2. Validação: revisar histórico de comandos
3. Erradicação: resetar credenciais, revalidar pareamento
4. Recuperação: testar abertura/fechamento seguro
5. Lições: MFA, alertas críticos

## Assistente de Voz
1. Contenção: revogar sessões, bloquear comandos remotos
2. Validação: revisar histórico de voz
3. Erradicação: redefinir integrações
4. Recuperação: testar comandos seguros
5. Lições: alertas para ações sensíveis
